For the Plot

You came for the porn. We translated the plot.

A complete fan-translation workflow for Ren'Py visual novels: plain Python tools plus a written procedure that takes a game from archive to a drop-in language patch. It ships as a Claude Code plugin, but any AI assistant, or a person, can follow it end to end.

View on GitHub Latest release Read the playbook

The pipeline

decompile → extract strings → build a game profile
→ translate → QA → build patch → deploy

What it does

  • Token-safe. Every [variable], {tag} and escape in the source must survive into the translation, with tag nesting checked, so a line never crashes the game.
  • Character-aware. Per-character speech registers and per-pair pronouns for languages like Thai, where the right word depends on who is speaking to whom.
  • Thai and Chinese. Built-in conventions for Simplified and Traditional Chinese (punctuation, script purity, Mainland and Taiwan vocabulary) and locale guidance for Thai.
  • No source edits. The patch lives in its own folder and uninstalls by deleting it.
  • Bulk or by hand. Use an API provider (DeepSeek, OpenAI-compatible, Gemini, Anthropic, Claude Code CLI) for a first pass, or translate in your own session. A translation cache makes repeats and game updates free.
  • Stdlib only. Python 3.8+, no required dependencies, tested in CI.

Install

In Claude Code:

/plugin marketplace add Waiyakorn1879/for-the-plot
/plugin install for-the-plot@for-the-plot

Using another tool? Clone the repository and point your assistant at AGENTS.md.

Proven on real games

The workflow was built on full Thai translations of Being a DIK and Eternum. The repository includes a trimmed Eternum Thai profile as a worked example, and a synthetic Simplified Chinese example. No game text is published.

For the Plot is open source (see the license). It contains tools and style guides only; it does not distribute any game's scripts or translations.
