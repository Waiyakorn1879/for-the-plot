## 1. Register & Pronoun Harmony (ระบบระดับภาษาและคู่สรรพนาม)

In register-rich Thai visual novels, pronouns belong to the **pair** (relationship dyad), not just the speaker. Pronoun pairs must remain strictly consistent within each register and scene context:

### ตารางคู่สรรพนามมาตรฐาน (Pronoun Dyads)
| Relationship / Context | Speaker | Self | Addressee | Tone / Register |
|---|---|---|---|---|
| **MC ↔ Main Girls** (Annie, Dalia, Alex, Nova, Penelope, Luna) | MC / Heroines | `ฉัน` / `เรา` | `นาย` / `เธอ` | สนิทสนม เป็นกันเอง สุภาพ วัยรุ่นมหาวิทยาลัย |
| **MC ↔ Nancy** | MC | `ผม` | `คุณ` / `แนนซี่` | สุภาพ ให้เกียรติผู้ใหญ่ |
| **Nancy ↔ MC** | Nancy | `ฉัน` / `แนนซี่` | `เธอ` / `หนุ่มน้อย` | เอ็นดู อบอุ่น หยอดคำหวาน |
| **MC ↔ Chang** | MC / Chang | `ข้า` / `ฉัน` | `เอ็ง` / `เพื่อน` / `นาย` | เพื่อนซี้คู่หูผู้ชาย กวนๆ เฮฮา |
| **Rivalry / Violent conflict** (MC vs Axel / Benjamin / Enemies) | MC / Rivals | `กู` | `มึง` | เดือด หยาบคาย สู้รบ ทะเลาะวิวาท |
| **Inner Monologue (ความคิดในใจ)** | MC | `ฉัน` / `เรา` | - | คิดคนเดียว ไม่สลับ `กู`/`มึง` ในใจ |

> [!CAUTION]
> **ห้ามจับคู่ "กู" กับ "แก" โดยเด็ดขาด:** หากใช้ `กู` ต้องคู่กับ `มึง` เสมอ ห้ามจับคู่ข้ามระดับภาษา

## 2. Character Voice Cards (บุคลิกและน้ำเสียงตัวละคร)

1. **Orion (โอไรออน - พระเอก):** หนุ่มวัย 18-20 ปี ปรับตัวเก่ง มีไหวพริบ ขี้เล่น ใช้ `ฉัน/เธอ` กับสาวๆ, `ข้า/เอ็ง` กับชาง, `ผม/คุณ` กับแนนซี่และอาจารย์
2. **Annie (แอนนี่):** เพื่อนสนิทวัยเด็ก สดใส ร่าเริง ขี้เล่น ใช้ `ฉัน/นาย` หรือแทนตัวเองว่า `แอนนี่` ไม่ใช้ `หนู/พี่`
3. **Luna (ลูน่า):** สาวน้อยอ่อนหวาน นุ่มนวล พูดเพราะ ใช้คำลงท้าย `ค่ะ/นะคะ` สุภาพ น่าทะนุถนอม
4. **Dalia (ดาเลีย):** สาวนักกีฬา ทอมบอย ติดเกม Eternum พูดจาห้าวๆ กวนๆ แต่แฝงความน่ารัก ใช้ `นะ/เนี่ย/ย่ะ/โว้ย`
5. **Alex (อเล็กซ์):** สาวนักกีฬาว่ายน้ำ มั่นใจ ตรงไปตรงมา ขี้แกล้ง ใช้คำพูดแนวแซวหยอกเย้า
6. **Penelope (เพเนโลพี):** สาวเนิร์ด/นางแบบ มั่นใจ เจ้าเสน่ห์ ฉลาด ชอบหยอดคำหวานและแซวโอไรออน
7. **Nova (โนวา):** แฮกเกอร์สาว หัวขบถ ปากคม ประชดเก่ง เท่ ฉลาดเป็นกรด
8. **Nancy (แนนซี่):** สาวใหญ่ อดีตพี่เลี้ยงเด็ก ใจดี อบอุ่น มีเสน่ห์ เรียกโอไรออนว่า `หนุ่มน้อย`

## 3. Slang & Profanity Policy (การแปลคำสแลงและคำหยาบ)

- **Don't sanitize:** ห้ามลดทอนระดับความหยาบหรือความเผ็ดร้อนในฉาก 18+ หรือฉากต่อสู้ หยาบให้แปลหยาบ สุภาพให้แปลสุภาพ
- **Star Wars / Pop Culture references:** แปลและรักษาเจตนาการล้อเลียนให้ตรงกับวัฒนธรรมป๊อป (เช่น Admiral Ackbar = พลเรือเอกอัคบาร์)
- **Souls-like UI terms:** คงภาษาอังกฤษเดิมไว้ (เช่น `YOU HAVE DIED`, Gallery replay tags)
- **Formatting:** คงแท็กเอฟเฟกต์ `{i}...{/i}`, `{b}...{/b}`, `{image=...}`, `[variable]` ครบถ้วน 100%
